## Jak uruchomić i co klikać

```bash
npm test && npm run build
python3 -m http.server 8000 --bind 0.0.0.0
# /#egungun — pełnoekranowa kartoteka (sekcje I→VI), linki źródłowe, motyw
# /#skity — Baza Skitów; /#skit:plotno-i-kamien — sam SKIT
# /#nowosci — dziennik zmian (feed z meta)
```
Warto sprawdzić na żywo: rozciągnięcie okna (mapa nie skacze, brak ucięcia
biegunów), przełącznik ☾/☀ przy otwartej kartotece i przy otwartym skicie,
klik w uczestnika skitu (wraca do karty), Esc (warstwa → kartoteka).
