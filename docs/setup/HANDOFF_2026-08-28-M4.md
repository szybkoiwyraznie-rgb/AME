## Pułapki tej sesji

- `indexOf` w testach kontraktowych: jeśli wzorzec występuje wcześniej w pliku,
  wycinek jest pusty i test wyje mylnie (albo przechodzi mylnie) — sprawdzaj
  kolejność wystąpień.
- `npm test | grep` nie jest bramą: commit „po grepu” ogłosił 99/99 przy 98/99
  (sprostowane w `93f9792`). Bramą jest **kod wyjścia** `npm test`.
- Komunikaty commitów: przez `git commit -F -`/plik, bez backticków w `bash -c`,
  i bez wtrąceń obcosłownych (zdarzyło się jedno).
